Одностраничный sales landing для AI-курса, построенный вокруг монохромной
визуальной системы, полноэкранного видео, glass UI и scroll-driven
интерактивности.

Страница выстроена как цельный путь пользователя, а не как набор отдельных
секций: визуальный hero знакомит с продуктом, программа показывает
содержание курса, pricing переводит пользователя к регистрации, а
checkout-flow завершает сценарий непосредственно на frontend.

Курс, наставники и программа вымышлены. Видео в hero взято из stock
footage и используется как визуальный материал для портфолио-проекта.

## Визуальное направление

Интерфейс построен на сдержанной черно-белой палитре, крупной типографике,
большом количестве свободного пространства, полупрозрачных поверхностях и
полноэкранном видео в hero.

Glass-эффект используется точечно. Навигация, мобильное меню и отдельные
карточки используют blur, saturation и inset highlights, создавая глубину
без превращения всего интерфейса в набор стеклянных панелей.

## Структура landing page

Страница выстроена в последовательность:

Hero → Program → How it works → Pricing → Signup

Каждая секция выполняет отдельную роль в sales-сценарии, сохраняя при этом
единую визуальную систему.

Hero объединяет зацикленное видео, навигацию, headline и дополнительную
информацию в пределах одного экрана. Далее программа переводит внимание от
визуального впечатления к конкретному содержанию курса, а pricing
становится переходом к интерактивной регистрации.

## Анимации как часть интерфейса

Анимация используется для поддержки структуры страницы, а не просто как
декоративный эффект.

Карточки программы реагируют на положение страницы через контролируемые
эффекты наклона и масштабирования. Секция с этапами использует
последовательное появление элементов при входе в viewport.

![Как это работает](docs/preview/02-how-it-works.png)

У навигации есть собственное небольшое взаимодействие: кнопка открытия
меню превращает `+` в `×`.

Анимации реализованы через `motion` и его scroll-инструменты, поэтому
поведение остается непосредственно связано с компонентами, которые его
используют.

## Pricing и checkout

Карточки тарифов открывают многошаговый сценарий:

Регистрация → Оплата → Успешное завершение

Форма содержит клиентскую валидацию и сохраняет ту же визуальную систему,
что и основной landing page.

Checkout намеренно симулируется на frontend. Backend и платежный
процессор не подключены, а данные банковской карты никуда не отправляются
и не сохраняются.

![Pricing](docs/preview/03-pricing.png)

## Локализация

Landing page поддерживает русский и английский языки через собственный
translation layer.

Все строки интерфейса хранятся в общем словаре
`src/i18n/translations.js`. Context provider управляет активным языком, а
выбранная локаль сохраняется в `localStorage`.

Переключение языка происходит непосредственно внутри страницы и не
требует отдельных маршрутов или дублирования страниц.

## Адаптивность

Hero построен вокруг полноэкранной композиции, в которой навигация,
фоновое видео и нижний контентный блок существуют независимо друг от
друга.

Благодаря этому основная визуальная структура сохраняется при разных
высотах viewport и не зависит от одной фиксированной desktop-композиции.

Остальные секции используют responsive layout, который адаптирует
отступы, расположение карточек, навигацию и типографику под небольшие
экраны.

## Структура frontend

Основные секции страницы и общие функции разделены на отдельные
React-компоненты.

```text
src/
├── assets/
├── components/
├── i18n/
├── App.jsx
├── index.css
└── main.jsx
```

Компоненты содержат секции страницы и интерактивные элементы, а
локализация вынесена в отдельный модуль и не смешана непосредственно с UI.

В проекте не используются Tailwind или готовая component library.
Стилизация выполнена на обычном CSS, что дает полный контроль над
визуальной системой, glass-эффектами, типографикой, layout и responsive
behavior.

## Техническая основа

В проекте используются:

- React 19 для интерфейса
- Vite для разработки и production-сборки
- Motion для scroll-linked и интерфейсных анимаций
- Lucide React для иконок
- обычный CSS для визуальной системы
- собственный RU/EN translation layer для локализации

## Деплой

Проект размещен на GitHub Pages.

Изменения, отправленные в `main`, запускают GitHub Actions workflow,
который собирает приложение и публикует получившуюся директорию `dist`.

В конфигурации Vite используется base path `/ai-sales-landing/`,
необходимый для размещения проекта внутри GitHub Pages.

## Границы проекта

NeuralKinetics является портфолио-концепцией, а не реальной платформой
онлайн-обучения.

Контент продукта, наставники и программа курса вымышлены. Сценарий
регистрации и оплаты демонстрирует предполагаемое frontend-взаимодействие,
а реальная обработка платежей и сохранение данных находятся за пределами
проекта.

## Итог

NeuralKinetics делает акцент на той части sales landing, которую
пользователь воспринимает в первую очередь: визуальной иерархии,
анимации, взаимодействии и переходе от презентации продукта к конверсии.

В результате получился одностраничный интерфейс, объединяющий
полноэкранный video hero, сдержанный glass UI, scroll-based motion,
двуязычный контент, адаптивную верстку и полноценный симулированный
сценарий от регистрации до checkout.
