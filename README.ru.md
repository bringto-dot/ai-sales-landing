# NeuralKinetics

**[Живая версия](https://bringto-dot.github.io/ai-sales-landing/)**

*[Read in English](README.md)*

Одностраничный лендинг для продажи курса, сделанный как проект в портфолио,
чтобы попрактиковаться в минималистичной чёрно-белой эстетике на React:
полноэкранный хиро с видео, стеклянный (glassmorphism) UI, анимации при
прокрутке и настоящая мультиязычность — без использования UI-библиотек.

Курс, менторы и программа обучения — вымышленные. Видео в хиро-блоке —
настоящая стоковая съёмка, использованная как контент, под который
проектировался сайт.

![Hero](docs/preview/01-hero.png)

## Что показывает этот проект

- **Хиро-блок, который не разваливается от реального контента.** Навбар,
  зацикленное фоновое видео и нижний текстовый блок позиционируются
  независимо друг от друга (fixed / absolute / absolute), поэтому вёрстка
  не схлопывается сама в себя на низких viewport — баг, который я поймал
  и исправил в процессе разработки.
- **Liquid glass — точечно, а не везде.** `backdrop-filter: blur + saturate`
  с внутренними бликами на пилюлях навбара, выпадающем меню и паре карточек —
  не на каждой поверхности, а только там, где стеклянная панель в стиле iOS
  читается как акцент, а не как шум.
- **Анимации по делу.** Наклон/масштаб карточек программы, привязанный к
  прокрутке (`useScroll` + `useTransform` из `motion`), поочерёдное появление
  карточек шагов при скролле и переключатель меню, где `+` плавно
  превращается в `×`, а не просто показывает/скрывает текст.
- **Настоящая мультиязычность, не плагин.** Каждая строка живёт в одном
  словаре (`src/i18n/translations.js`) с ключами `ru`/`en`; контекст-провайдер
  переключает активный язык и запоминает выбор в `localStorage`.
- **Фронтенд, который ведёт себя как с бэкендом.** Карточки тарифов
  открывают модалку регистрация → оплата → успех с настоящей валидацией на
  клиенте, хотя на сервере ничего не подключено (это явно указано ниже, а не
  спрятано).

## Стек

React 19 + Vite, `motion` (Framer Motion) для анимаций, обычный CSS (без
Tailwind и UI-библиотек), `lucide-react` для иконок.

```bash
npm install
npm run dev
```

При пуше в `main` запускается GitHub Actions
(`.github/workflows/deploy.yml`), который собирает проект и публикует
`dist/` на GitHub Pages.

## На заметку тем, кто смотрит код

- У модалки оформления заказа нет бэкенда. При отправке она проходит шаги
  регистрация → оплата → успех на клиенте; данные карты никуда не
  отправляются и не сохраняются. Чтобы подключить реальный платёжный
  процессинг, достаточно заменить два обработчика `onSubmit` в
  `src/components/AuthModal.jsx`.
- В `vite.config.js` задан `base: '/ai-sales-landing/'`, чтобы собранные
  файлы корректно резолвились под сабпутом GitHub Pages — учтите, что
  локальная разработка идёт по адресу `localhost:5173/ai-sales-landing/`,
  а не с корня.
